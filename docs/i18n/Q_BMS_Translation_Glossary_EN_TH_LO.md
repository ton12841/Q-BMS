## Style rules

- ไม่ฝืนแปลคำที่คนทำงานใช้ภาษาอังกฤษเป็นปกติ เช่น HRM, CRM, C-Level, Dashboard
- คำอธิบายเขียนให้เข้าใจหน้าที่ของเมนู ไม่แปลโครงสร้างประโยคอังกฤษตรงตัว
- คำเดียวกันต้องใช้เหมือนกันทุก Module
- English เป็น source/fallback
- Thai/Lao ควรผ่านการ review โดยผู้ใช้จริงก่อน APPROVED
