# Q BMS v2.3.3.2 — Typography Readability Polish

This patch improves readability without changing the visual hierarchy or business flow.

## Platform typography scale

- Caption: 12px
- Meta: 13px
- Small: 14px
- Body: 15px
- Card title: 17px
- Section title: 19px
- Page title: 24px
- Display: 30px

## Targeted fixes

- Employee Master helper text is no longer hard-coded to 10px.
- Summary labels, table headers and secondary metadata are more readable.
- Development Preview chip text is increased.
- In-module Real Data / QA Data Mode bar is easier to read.
- QA Data Mode table body is 14px and headers are 13px.
- QA metric labels and explanatory copy are larger.
- QA rules and empty-state text are larger.
- Status badges remain compact to preserve density.

No database or backend business behavior changes.
