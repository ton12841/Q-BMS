# Q BMS Typography System — v2.0.7.0

Q BMS uses a readable desktop SaaS / BMS typography scale.

## Core scale

| Role | Target size |
|---|---:|
| Display / hero title | 25–31 px |
| Page title | 18 px |
| Section title | 15 px |
| Card / primary item title | 14 px |
| Body / primary table text | 12–14 px |
| Helper / secondary text | 11–12 px |
| Metadata | 11 px |
| Small badge / uppercase label | 10 px |

## Rules

- Normal descriptive text should not be 8–9 px.
- Table body text should normally be at least 12 px.
- Breadcrumbs should be 12 px.
- Status badges and compact metadata may use 10–11 px.
- Thai and Lao must use the same visual hierarchy as English.
- Future modules should use the shared `--qbms-font-*` tokens from `globals.css`.
- Do not shrink text just to fit a card; allow wrapping or increase card height instead.
