# Q BMS v2.2.13.0 — Super Admin i18n Completion

Completes global Language Switcher support for the older Super Admin child tools:

- User & Identity Management
- User Access Assignment
- Level / Grade Permission Policy
- Effective Permission Preview
- Audit Log

Supported languages:
- English
- Lao
- Thai

Technical identifiers such as Role codes, Permission codes, Entity types and Audit action codes remain canonical and are not translated.

This patch is frontend-only. No database migration, backend change or npm install is required.
