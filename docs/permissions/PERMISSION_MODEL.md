# Permission Model

Every employee receives Employee Workspace base access.

Tool access is additive and controlled by permissions.

Examples:

- `EMPLOYEE.PROFILE.SELF_VIEW`
- `EMPLOYEE.PROFILE.SELF_EDIT`
- `HRM.ACCESS`
- `HRM.EMPLOYEE.CREATE`
- `HRM.EMPLOYEE.EDIT`
- `HRM.ONBOARDING.REVIEW`
- `SUPER_ADMIN.ACCESS`

Future permission evaluation should support:

1. Tool access
2. Feature access
3. Action access
4. Data scope
5. Role templates
6. Explicit overrides when approved
